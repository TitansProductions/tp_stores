# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Added leveling support for unlocking specific products to be bought or sold through a leveling type (`tpz_leveling` by default, you can also use your own). Also, on selling, there is an extra possibility to allow extra money reward increased by level.

## Modified Files:

- client/tp-client_nui.lua
- server/tp-server_callbacks.lua
- html/css/style.css
- html/js/script.js
- html/js/locales/locales-en.js (or another locale that you have created, a new locale must be added - check notes).
- config.lua
- fxmanifest.lua

## Notes:

- Add the following on the `config.lua` file below `Config.AdvancedSliderInput`:

```lua

-- Set to true to enable a leveling system - BEFORE YOU DO - READ:
-- By default we use tpz_leveling as an example, you must add your own leveling system if you are interested! WE DO NOT PROVIDE A LEVELING SYSTEM.
-- Checkout: server/tp-server_escrow_ignore.lua
Config.LevelingSystem = false -- 2.6.6
```


- Add leveling data on the item(s) you want to be having a required level or extra money rewards based on level (for selling only).

This is for **BUYING** items only, without `extra_dollars_reward_by_level` data.

```lua
leveling = { enabled = true, type = 'farming', required_level = 3 }
```

This is for **SELLING** items only, with `extra_dollars_reward_by_level` data.

```lua
leveling = { enabled = true, type = 'mining', required_level = 0, extra_dollars_reward_by_level = 0.05 }
```

You can add this new data after `category` on an item.

__Example:__

```lua
{ label = "Silver", item = "silver", currency = "dollars", price = 0.15,   canGiveItems = false, givenItem = {}, givenAmount = {}, givenDisplay = {}, category = "mineralores", leveling = { enabled = true, type = 'mining', required_level = 0, extra_dollars_reward_by_level = 0.015 } },
```

**If you are not having leveling data, there will not be any errors and no problems will occured.**
