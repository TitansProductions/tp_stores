# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Added leveling support for unlocking specific products to be bought or sold through a leveling type (`tpz_leveling` by default, you can also use your own). Also, on selling, there is an extra possibility to allow extra money reward increased by level.

## Modified Files:

- client/tp-client_nui.lua
- server/tp-server_callbacks.lua
- html/css/style.css
- html/js/script.js
- html/js/locales/locales-en.js (or another locale that you have created, a new locale must be added - check notes).
- config.lua
- fxmanifest.lua

## Notes:

- Add the following on the `config.lua` file below `Config.AdvancedSliderInput`:

```lua

-- Set to true to enable a leveling system - BEFORE YOU DO - READ:
-- By default we use tpz_leveling as an example, you must add your own leveling system if you are interested! WE DO NOT PROVIDE A LEVELING SYSTEM.
-- Checkout: server/tp-server_escrow_ignore.lua
Config.LevelingSystem = false -- 2.6.6
```
